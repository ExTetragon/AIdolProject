# AI娘物种立绘 (AIdol Portrait)

## 模组简介

**AI娘物种立绘（AIdol Portrait）** 是一款面向《群星》（Stellaris `v4.5.4`）的 AI 娘化物种静态 2D 立绘扩展模组。模组采用非覆盖式扩展设计，不修改原版物种与原有肖像，可与原版及其他外观模组共存。

- **当前版本**：`0.1.0`
- **适用版本**：Stellaris `v4.5.4`

## 当前已实现功能

- **角色立绘阵容（占位测试版）**：内置 8 位初始 AI 娘角色（Claude、ChatGPT、Gemini、Grok、Kimi、Qwen、DeepSeek、GLM）的占位立绘，合并为同一物种可选变体，覆盖帝国创建、物种界面、人口、领袖与统治者等游戏内场景（正式美术立绘尚未打包合入）。
- **多外观分类接入**：同时支持在游戏「人形」「合成人」「义体」「机械」四个物种外观分类中选用，并完整保留原版肖像。
- **语音与基础界面支持**：已配置原版自带的问候语音（无需额外 DLC），并提供模组启动器封面图与简体中文本地化支持。
