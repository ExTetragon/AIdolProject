# AI娘物种立绘（AIdol Portrait）

适用于《群星》（Stellaris）4.x 版本的 AI 娘化静态物种立绘模组，当前版本为 **0.1.1**，已在游戏 **4.5.4** 中正常运行。

## 模组简介

本模组收录多款主流 AI 工具与大模型的拟人化角色立绘，以独立物种外观的形式加入《群星》，与游戏原版物种立绘共存，可在开局创建帝国或游玩过程中自由选用。

## 已实现功能

- **31 位角色，共 75 张立绘**：涵盖 Claude、GPT、Gemini、Grok、Kimi、Qwen、Deepseek、GLM、dsh、Seed、Mistral、MiniMax、ERNIE、Cloudflare、Gitee、GitHub、GitHub Copilot、GitLab、Hugging Face、JEV、Llama、LobeHub、Microsoft Copilot、Novel AI、OpenCode、Perplexity、RWKV、StepFun、Zcode、Ascend、Hunyuan，默认展示角色为 Claude。
- **半身构图与画面适配**：全部 75 张立绘均已适配游戏内展示比例，将原全身作品逐张调整为半身取景，保留原有的近景与半身构图，并兼顾人物透明去背与部分作品的场景氛围背景，确保人物在各类游戏窗口中清晰完整。
- **全场景与多分类支持**：已接入**人形、机械、合成人、义体**四个物种外观分类，并在创建帝国、物种、人口、领袖与统治者五个游戏场景中完整生效。
- **AI 娘主题名字列表与随机物种名（`AIDOL`）**：提供统一的中英双语可选名称列表（禁用随机 AI 帝国抽取），涵盖四层权重人名池（品牌全名、11 系列纯英文家族组合、社区昵称、经典 AI 泛化组合及 23 项王室/机械核心全名）、13 类专属舰种与共用殖民船名、24 种模型/硬件架构船级、25 支独特舰队与 `$ORD$算力集群` 序号模板、兼容人形与机械全兵种的陆军命名、40 个通用与 7 类气候行星名，以及 6 组配套随机物种/母星/恒星名。
- **配套体验**：为角色搭配了原版女性问候语音，提供简体中文与英文界面本地化文本，并配有模组启动器封面图。
