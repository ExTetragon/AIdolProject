# AI娘物种立绘（AIdol Portrait）

适用于《群星》（Stellaris）4.x 版本的 AI 娘化静态物种立绘模组，当前版本为 **0.1.2**，已在游戏 **4.5.4** 中正常运行。

## 模组简介

本模组收录多款主流 AI 工具与大模型的拟人化角色立绘，以独立物种外观的形式加入《群星》，与游戏原版物种立绘共存，可在开局创建帝国或游玩过程中自由选用。

## 已实现功能

- **32 位角色，共 78 张立绘**：收录多款主流 AI 大模型与工具的拟人化立绘（含 Claude、GPT、Gemini、Deepseek、Qwen、Kimi、豆包等，默认展示 Claude），均已完成游戏内半身取景与比例适配。
- **多分类与全场景接入**：支持**人形、机械、合成人、义体**四种物种外观分类，在创建帝国、物种、人口、领袖与统治者界面中完整生效，与原版立绘独立共存。
- **AI 娘主题名字列表与随机物种名**：提供中英双语可选名称列表（`AIDOL`，不参与随机 AI 帝国抽取），覆盖领袖/统治者、各类舰船与船级、舰队、陆军、行星及配套随机物种名，兼容人形与机械开局。
- **基础配套**：配置原版女性问候语音、简中/英文双语本地化与启动器封面图。
